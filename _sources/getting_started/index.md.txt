# Getting Started

Start here if you're new to instrumentserver. These pages take you from installation
to a running Server and your first parameter call, then explain how the pieces work
together.

Read them in order for a complete introduction:

1. [Installation](installation.md) sets up instrumentserver and checks that its command
   line tools are available.
2. [Quickstart](quickstart.md) starts a Server, creates a dummy instrument, and controls
   it from a separate Python session.
3. [How it works](how_it_works.md) introduces Servers, Clients, Proxy Instruments,
   Blueprints, and Broadcasts.
